# Cowork PPTX 제작과 검증

사용자가 Cowork로 전달할 범위를 선택할 수 있도록 먼저 전달용 브리프를 로컬에 작성한다. 공고의 공개 원문과 제출 규격, 공개에 동의한 사례·이미지, 슬라이드별 메시지와 사실 근거, 파일명·페이지·용량·제출 형식을 포함한다. 필요하면 제출용 문구와 내부 확인 메모를 별도 파일로 둔다. 커리어 원본 전체, 로그인 정보, 연락처, 내부 이름과 미공개 자료는 브리프에서 제외한다.

Cowork 사용과 전달할 정확한 자료에 대해 승인을 얻는다. 사용자가 직접 넘기는 경우 복사할 프롬프트와 해당 자료만 제공한다. 실행할 수 있는 Cowork 세션이 있고 전달을 요청받았으면 승인된 자료만 사용하고, 산출 파일을 돌려받을 경로를 확인한다. Cowork가 없으면 제공한 브리프로 제작을 이어갈지 사용자가 정한다.

반환된 `.pptx`를 로컬로 받아 실제로 열고 모든 슬라이드를 렌더링해 검토한다. 사용 가능한 프레젠테이션 스킬의 PPTX 검증 흐름을 활용한다. 아래 항목을 확인한다.

- 공고 규격에 맞는 파일 형식·슬라이드 수·용량·이름과 파일이 열리는지
- 글꼴 대체, 잘림·겹침, 숫자·기간·역할의 근거, 이미지·링크의 공개 권한
- 숨은 슬라이드·발표자 노트·주석·문서 속성·연결 파일에 불필요한 개인정보나 내부 정보가 남았는지
- 이력서·폼 답변과 역할·수치가 일치하는지, 지원 사이트에서 요구한 형식을 고른 것인지

수정 후 다시 확인한다. PPTX에서 PDF로 변환해야 하는 공고라면 실제 업로드용 최종 PDF도 열어 확인한다. 렌더링이나 검증에 필요한 파일이 없으면 필요한 파일을 요청한다. 확인을 끝낸 파일만 패킷에 넣는다.
